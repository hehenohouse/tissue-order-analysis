# Archived original implementation

`code_2_original.py` is the unmodified 2,597-line script that was present before Tissue Order Analysis was converted into a package.

It is retained because the source directory did not yet have Git history when the refactor began. It is **not installed, imported, tested, or supported** and contains known correctness problems, including mixing RGB renderings with numerical ψ values. Use the implementation in `src/tissue_order_analysis/` instead.
